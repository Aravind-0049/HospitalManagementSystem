# Hospital Management System — Full Stack Java Project

## Technology
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API, Responsive Grid)
- **Backend:** Java 21, Spring Boot 4.x, Spring Data JPA, Hibernate, Maven
- **Database:** In-memory H2 Database (MySQL compatibility mode)

- **Live Application:** [https://hospital-management-system-backend-6-iats.onrender.com](https://hospital-management-system-backend-6-iats.onrender.com)

---

## 📋 Modules & Features
- **Hospital Dashboard:** Real-time counter of total patients, doctors, appointments, and bills.
- **Patient Management:** Register patients with complete demographic details and medical history.
- **Doctor Management:** Add and manage doctors, departments, and specialties.
- **Appointment Scheduling:** Book and manage patient appointments with doctors and time slots.
- **Billing Management:** Generate hospital bills, manage payment status, and track billing history.
